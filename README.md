# End-to-End Job Market Analytics Platform

A comprehensive platform to analyze job market trends, run ETL pipelines, view insights on a dashboard, and interact with a job-search assistant chatbot.

## Directory Structure

- `api/` - Fast API endpoints and controllers
- `backend/` - Core backend logic and services
- `chatbot/` - Chatbot/LLM assistant codebase
- `config/` - Configuration files and environment setup
- `dashboard/` - Frontend/Dashboard UI (e.g., Streamlit, React)
- `data/` - Data storage:
  - `raw/` - Raw data collected from APIs/web scraping
  - `processed/` - Cleaned and transformed data ready for analysis
- `database/` - DB models, schemas, and migrations
- `docs/` - Project documentation and design specs
- `etl/` - Data ingestion, cleaning, and transformation pipelines
- `logs/` - Logs generated by the application
- `notebooks/` - Jupyter Notebooks for exploratory data analysis (EDA)
- `tests/` - Unit and integration tests
- `utils/` - Shared helper functions and utility modules
